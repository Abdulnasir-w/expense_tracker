1. ARCHITECTURAL DECISIONS & CORE PRINCIPLES
--------------------------------------------------------------------------------
1. Integer Minor Units (No Floating-Point Math):
   - All monetary values are strictly stored as integers (`amountMinor`), preventing
     IEEE 754 floating-point inaccuracies (e.g. 0.1 + 0.2 = 0.30000000000000004).
   - $12.50 USD is stored as 1250 cents.
   - Handled via `CurrencyFormatter` with custom decimal digits per currency
     (e.g., USD/PKR = 2 decimals, JPY = 0, KWD = 3).

2. String UUIDs (Never Auto-Increment IDs):
   - Every entity (Transactions, Categories, Accounts, Budgets, RecurringRules)
     uses a cryptographically random UUID v4 (`uuid` package).

3. Referenced by ID, Never by Name:
   - Transactions store `categoryId` and `accountId` (and `toAccountId` for transfers).
   - Category renames or account modifications never corrupt transaction history.

4. Versioned Schema & Auto-Migration:
   - Hive `app_settings` box maintains `schema_version` (Version 2).
   - On startup, `HiveService` inspects the version, seeds default accounts and
     categories, and automatically migrates legacy entries.

5. Computed Balances:
   - Balances are NEVER stored statically; they are computed dynamically from the
     transactions ledger:
     accountBalance = initialBalance
                    + sum(income into account)
                    - sum(expenses from account)
                    + sum(transfers into account)
                    - sum(transfers out of account)

2. TARGET DATA MODELS
--------------------------------------------------------------------------------
- Transaction:
  id (UUID), type (income | expense | transfer), amountMinor (int), currencyCode,
  categoryId (UUID), accountId (UUID), toAccountId (UUID?), date, title, note,
  exchangeRate?, baseAmountMinor?, recurringRuleId?, createdAt, updatedAt.

- Category:
  id (UUID), name, iconKey, colorValue, type (income | expense | both),
  isArchived, sortOrder.

- Account:
  id (UUID), name, type (cash | bank | wallet | card), currencyCode,
  initialBalanceMinor, colorValue, iconKey, isArchived.

- Budget:
  id (UUID), categoryId? (null = overall monthly), limitMinor, period (monthly).

- RecurringRule:
  id (UUID), type, amountMinor, currencyCode, categoryId, accountId, toAccountId?,
  title, note, frequency (daily | weekly | monthly | yearly), interval,
  startDate, endDate?, nextDueDate, isActive, autoAdd.
